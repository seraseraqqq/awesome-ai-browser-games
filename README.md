# Awesome AI Browser Games

[![136 tracked projects](https://img.shields.io/badge/projects-136_tracked-1b1f3b)](https://zadely.com/games/) ![updated 2026-10-26](https://img.shields.io/badge/updated-2026--10--26-1b1f3b)

> A curated directory of browser games built or assisted by AI, with separate sections for AI-powered gameplay, independent projects, fan games and classic browser runtimes. Maintained by [Zadely](https://zadely.com).

This edition tracks **136 projects**: 90 AI-built or AI-assisted games, 1 AI-powered gameplay project, 12 other independent games/demos, 7 fan games, 18 classic browser runtimes, and 8 status or asset-advisory records. These categories describe different uses of AI; they are not interchangeable.

Each game title links to its setup, controls and source notes on Zadely. **Website** links open the published project or creator page. Inclusion does not mean a game is open source, officially licensed by a franchise owner, or tested on every device.

**Legend:** 📱 documented touch inputs, not a guarantee of phone performance · 💾 original game data required · 🏆 published jam award. AI tool credits may come from creator notes or identified community/game-jam sources; the linked guides retain that context.
